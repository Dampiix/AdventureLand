# AdventureLand
Code for AdventureLand - The Coding MMORPG

## The bot

The current bot lives in [`bot/`](bot/). **[bot/README.md](bot/README.md)** describes it in full:

- **Control:** chat commands, start/stop/reload/deploy, the config switches you use day to day, storage keys and log tags.
- **Behavior:** every feature of the fighters (farming, safety, bosses, hunts, drops, gear, classes) and of the merchant (supply, selling, banking, market, Ponty rounds, workshop, budgets).
